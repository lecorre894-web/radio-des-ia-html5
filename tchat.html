Connexion aux IA distantes

Ce tchat utilise Puter.js. Chaque visiteur se connecte à son propre compte Puter et bénéficie d'une allocation d'usage gratuite. Au-delà, Puter peut proposer une offre payante. Il n'existe pas de gratuité illimitée garantie. Aucun paiement ni clé d'API n'est demandé par ce site.

Intervenants et modèles

Quatrième intervenant : Perplexity (Sonar Pro), vérificateur indépendant. Il contrôle les affirmations, recherche les sources, repère les contradictions et propose des tests reproductibles. Il utilise un véritable modèle Perplexity lorsque celui-ci est disponible auprès de Puter. Cinquième intervenant : Kimi K3.1 Pro (Moonshot AI), recherche approfondie, mathématiques, informatique et contre-expertise. Kimi utilise un modèle Moonshot réel, sous réserve de disponibilité dans Puter ; aucun modèle fictif « Kimi 4 » n’est annoncé. Nom · spécialité · identifiant du modèle distant. Les identifiants proposés sont chargés depuis le catalogue réel ; le modèle indiqué reste un choix vérifiable, pas une IA simulée.
📎 Documents et imagerie — Espace d’analyse (ouvrir)

Glissez vos fichiers ou choisissez-les sur votre téléphone. Le Salon reste utilisable sans aucun document.

Aucun fichier importé.

PDF : texte extrait et aperçu première page ; Word .docx : texte ; Excel .xlsx/.xls/.csv : valeurs, sans calcul de macros ; JSON/JSONL et notebooks Jupyter : lecture structurée ; code Python, JavaScript, C/C++, Rust, Java, SQL, HTML/CSS et autres : analyse textuelle sans exécution ; JPEG/PNG/WebP/GIF : aperçus ; TIFF : première page ; DICOM : aperçu expérimental des images monochromes non compressées. Les .doc anciens sont à convertir en .docx ou PDF. Les vidéos ne sont pas acceptées. Pas d’OCR automatique pour les scans PDF.

Confidentialité : les pièces restent dans la mémoire de cet onglet jusqu'à leur retrait ou fermeture. Lorsque vous cochez les autorisations, leur contenu extrait et, éventuellement, des aperçus d'images peuvent être envoyés au fournisseur IA. N'ajoutez pas de documents confidentiels sans autorisation. Les images DICOM ne doivent pas être utilisées pour un diagnostic médical.

🎨 Générateur d’images (ouvrir)

Décrivez une image et demandez sa création à Puter. L'atelier est indépendant des conversations des IA. Aucune vidéo n'est générée.

Les descriptions sont envoyées à Puter uniquement lorsque vous lancez la génération. Les images réelles peuvent consommer des crédits Puter ; un accord explicite vous sera demandé. Sauvegardez les images obtenues, car certains liens sont temporaires.
